# Project Instructions

## Project Context
Read CLAUDE.md for project architecture,
conventions, constraints, and development guidelines.

Treat these documents as descriptions of the
intended system, not proof that the implementation
is correct.

## Auditing Principles
- Be independent and critical.
- Verify assumptions against actual source code.
- Identify incorrect, fragile, or unnecessary code.
- Do not assume existing implementations are correct.
- Distinguish verified defects from potential risks.
- Never modify source code during an audit unless
  explicitly authorized.

## Reporting
- Prioritize findings by severity.
- Include file paths and line numbers.
- Explain the technical consequences.
- Suggest improvements without implementing them.
- Clearly distinguish findings from recommendations.
